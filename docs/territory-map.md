# Territory Map (`/admin/territories`)

Replaces Mapline ($1,700/yr): an interactive US + Canada map where Sales tracks
which **rep firm** owns which territory, with pins at rep locations and a
companion directory of every rep. Shipped 2026-07-27 (migration 068).

## Who can see / edit

- **View**: anyone holding the `deals` permission (Sales + admin by default) —
  the page shares the perm with the CRM/Performance pages via its own
  `ADMIN_PATH_PERMS` entry (`lib/roles.ts`), so no new permission was seeded.
- **Edit** (paint territories, add firms/reps/pins): **admin and sales roles
  only** — enforced server-side by `requireTerritoryAuth({ write: true })`
  (`lib/api-auth.ts`). A scoped role granted `deals` later sees the map
  read-only. Every write is audit-logged (`territory.*` actions).

## Data model (migration 068 — extends the dormant CRM layer, 062)

- Rep firms are **`companies` rows with `kind='rep_firm'`**; reps are
  **`contacts`**. The CRM companies/contacts API routes do the directory CRUD.
- **`company_territories`** — one row per (firm, territory). `level` is
  `state` | `province` | `county`; `code` is a USPS state code (`TX`), Canadian
  province code (`ON`), or 5-digit county FIPS (`22033`). **Overlap is
  allowed** (unique per firm+geo, not per geo): the per-assignment
  `exclusivity` text carries the arrangement detail (Mapline's editable
  "exclusive in territory: *yes, for food and bev*"). Territories with one
  owner fill with the firm's color; shared ones fill neutral slate with all
  owners listed on hover.
- **`company_locations`** — pins. Multiple per firm; `lat`/`lng` NULL means
  "not placed yet". Address fields are nullable — the **sensitive personal
  fields (home addresses, personal phone/email) were deliberately not imported
  yet**; a later fuller import is additive. `contact_id` is the seam for
  per-rep pins (phase 3).
- **`companies.map_color`** — the firm's fill, from the curated 12-color
  palette in `lib/territories.ts`. Auto-assigned (least-used first) when a firm
  gets its first territory; changeable from the swatch picker in the firm
  panel. Stored, not hashed — hashes collide with no way to fix them.

## Map stack

- **maplibre-gl** + **OpenFreeMap** vector tiles (no API key, production use
  permitted, free) — `positron` in light mode, `dark` in dark mode. Both style
  URLs verified live 2026-07-27; if one ever 404s, fall back to positron for
  both themes in `MapCanvas.tsx`.
- All map-engine risk is contained in `app/admin/territories/MapCanvas.tsx`:
  - `map.setStyle()` (theme switch) **destroys every custom source/layer**;
    the idempotent `ensureLayers()` re-adds them on every `style.load`. Never
    add a source or layer anywhere else.
  - The map mounts once; StrictMode double-mount is handled by the cleanup's
    `map.remove()`.
- **Boundaries** are committed TopoJSON in `public/geo/` (public-domain
  Natural Earth 1:50m admin-1 for states/provinces, Census 1:20m cartographic
  for counties), generated by `node scripts/build-geo.mjs` (manual, not
  prebuild — boundaries don't drift with `npm install`).
  **Do not use `us-atlas`** — its TopoJSON is pre-projected to Albers and
  cannot be overlaid on a real map. Counties (~1.7MB) are fetched lazily only
  when county assignments exist or county paint mode is entered.
- Pins cluster via the GeoJSON source's built-in `cluster: true` (the "2"/"10"
  badges); cluster click zooms to expansion.

## Using it

- **Add a firm** → panel → "Rep firm". Firms are CRM companies — adding a name
  that already exists as a prospect/customer is refused (manage it in the CRM
  instead); an existing rep_firm is simply selected.
- **Paint territories** → select a firm → "Edit on map" → click
  states/provinces to toggle; switch the banner toggle to **Counties** for
  partial-state ownership (counties paint over state fills). Exclusivity notes
  are edited on each territory chip.
- **Pins** → firm → "Add location" → "Place on map" (crosshair) → click; drag
  the green marker to fine-tune; Done. There is **no geocoder** in v1 —
  placement is deliberate/manual (org_x/org_y precedent); a Nominatim-assisted
  "Locate" prefill is the planned phase 2.
- **Reps tab** — the flat Mapline-style directory (name, firm, title, email,
  phone) across all firms.

## Camera rules (deliberate — don't "helpfully" refit)

Only ONE gesture re-frames the map to a firm's whole footprint: picking that
firm from the panel list, or its "Show all" button in the detail view. Map
clicks never refit:

- **Click a pin** → zooms IN on that pin (`max(currentZoom, 8)`, so it can
  never zoom out) and selects its firm.
- **Click a fill** → identify only: names the owner in the panel, camera stays put.
- **Click a cluster** → expansion zoom, floored at `currentZoom + 0.75` so the
  click always visibly does something.

This is a fix, not an accident: refitting on pin click threw the camera to the
centroid of a multi-state footprint (clicking Hoffman & Hoffman's Charlotte
office jumped two states north), and `fitBounds`' `maxZoom: 7` zoomed the user
back OUT exactly when they were trying to get closer.

## Import from Mapline — RAN 2026-07-27

`scripts/import-mapline.mjs <csv> <curated.json> [--apply] [--geocode]` —
dry-run by default. Imported 34 firms / 71 territory assignments / 54 pins
(all geocoded city-level via Nominatim, 1 req/s; street addresses are stored
but never sent to the geocoder). The script is generic and committed; the CSV
and the curated JSON (firm renames, note overrides, territory assignments
hand-derived from the sheet's free-text notes) are business data and stay OUT
of this public repo. Idempotent — re-running with a fuller export only adds.

Import decisions of record:
- "Hoffman & Hoffamn" typo folded into Hoffman & Hoffman; ~14 Mid South
  duplicate rows deduped to its 3 real offices.
- The two "Norman S. Wright (…)" firms were renamed without parentheses —
  `normalizeCompany()` strips trailing parentheticals, so they'd have
  collided into one company.
- "Trane" imported as **Trane Canada** so it can never collide with a Trane
  customer/prospect record in the CRM.
- LJ Early Company got real county-level assignments (20 NY counties +
  Berkshire MA + all of VT) from its notes.
- Sub-state notes ("Northern Illinois", "East Michigan"…) became state-level
  assignments with the detail preserved in the exclusivity text — county-level
  carve-outs can be painted later in the UI.
- One personal cell/email (AMZ note) was withheld per the sensitive-data
  decision; no rep-person contacts were in the sheet, so the Reps tab starts
  empty.
